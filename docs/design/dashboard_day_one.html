Why a checklist and not a welcome card. Every item is derived from state you already hold — default_county is null, the partner count is 0, the deed count is 0. Step 1 in particular exists because the onboarding save failed silently; the page should be the thing that notices. A welcome banner can’t notice anything.
Status colour is never alone. Each pill carries a glyph and a word as well as a hue — “Didn’t save”, “Blocks recording” — so it survives colour-blindness, greyscale print and forced-colors mode.

Four stat tiles, zero charts — deliberately. A handful of headline numbers is a KPI row, not a bar chart; a single value is a stat tile, not a one-bar chart. Nothing here has a shape worth plotting. Note “Open drafts ▲2” is coloured as bad and “time to record ▼2d” as good — direction is coloured by whether the movement is good, not by its sign, and every delta names the period it compares to.
These tiles sit below the queue, not above it. They’re for the end of the week, not the start of the morning. The old dashboard put the counts up top where the work should be.
